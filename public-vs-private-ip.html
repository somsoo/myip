공인 IP와 사설 IP: 내 IP 주소는 왜 두 개일까

확인일: 2026년 10월 30일 · 아래 출처의 법령과 공식 발표를 기준으로 작성했습니다.

  • 공인 IP: 통신사가 준, 인터넷에서 보이는 주소. 이 사이트 첫 화면에 나오는 주소입니다.
  • 사설 IP: 공유기가 집 안 기기에 나눠 준 주소. 192.168.x.x, 10.x.x.x 등입니다.
  • 집 안의 여러 기기는 보통 공인 IP 하나를 함께 씁니다.
  • 이 사이트는 공인 IP를 알아내려고 외부 서비스(ipify)에 한 번 요청을 보냅니다.

두 주소의 차이

공인 IP사설 IP
누가 주나통신사(ISP)공유기
어디서 보이나방문한 웹사이트, 게임 서버 등 인터넷 전체같은 공유기에 연결된 기기끼리만
예시 범위그 밖의 주소10.0.0.0~10.255.255.255, 172.16.0.0~172.31.255.255, 192.168.0.0~192.168.255.255 (RFC 1918)

내 사설 IP 확인하기

  • 윈도우: 명령 프롬프트에서 ipconfig를 입력하고 'IPv4 주소'를 봅니다.
  • 맥: 시스템 설정 → 네트워크 → 연결된 네트워크의 '세부사항'에서 IP 주소를 봅니다.
  • 안드로이드·아이폰: 와이파이 설정에서 연결된 네트워크를 누르면 IP 주소가 나옵니다.

공인 IP는 기기 설정에 나오지 않는 경우가 많아, 이 사이트처럼 외부에서 보이는 주소를 알려 주는 서비스로 확인합니다.

IP는 왜 바뀌나

  • 가정용 인터넷은 대부분 유동 IP라서 공유기를 다시 켜거나 일정 시간이 지나면 바뀔 수 있습니다.
  • 휴대폰 데이터(LTE·5G)는 통신사 망 안에서 주소를 함께 쓰므로 자주 바뀌고, 같은 주소를 여러 사람이 쓰기도 합니다.
  • VPN을 켜면 웹사이트에는 VPN 서버의 IP가 보입니다.

IPv4와 IPv6

IPv4는 203.0.113.5처럼 점으로 구분한 4개 숫자(32비트)이고, IPv6는 2001:db8::1처럼 콜론으로 구분한 128비트 주소입니다. 통신사와 기기가 둘 다 지원하면 IPv6 주소가 표시될 수 있습니다.

IP로 알 수 있는 것

공인 IP로는 통신사와 대략적인 지역 정도를 추정할 수 있지만, 집 주소나 이름은 알 수 없습니다. 통신사 가입 정보와 연결하려면 수사기관의 법적 절차가 필요합니다.

자주 묻는 질문

내 IP가 보이면 위험한가요?

IP만으로 기기가 바로 해킹되지는 않습니다. 공유기 관리자 비밀번호를 바꾸고, 쓰지 않는 포트 포워딩을 꺼 두세요.

같은 집인데 휴대폰과 PC의 IP가 달라요.

와이파이에 연결된 기기는 같은 공인 IP를 쓰지만, 휴대폰이 데이터로 연결되어 있으면 통신사 망의 다른 주소가 보입니다.

이 사이트가 IP를 저장하나요?

이 사이트는 저장하지 않습니다. 공인 IP를 알아내기 위해 ipify 서비스에 요청을 보내며, 그 서비스의 처리 방식은 ipify 안내를 따릅니다.

출처

  • RFC 1918: Address Allocation for Private Internets (IETF)
  • ipify API
